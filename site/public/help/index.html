Overview

Woxus is a cross-platform desktop AI assistant that combines real-time voice conversation with local privacy and powerful desktop automation. It runs entirely on your machine, using a single WebSocket connection for speech-to-text, text-to-speech, interruption, and streaming reasoning — and keeps your memories, tasks, and settings stored locally.

Real-Time Voice

Low-latency voice conversations with barge-in — speak while Woxus talks.

Persistent Memory

Woxus remembers facts about you and injects them into every conversation.

Prompt Writer

Dictate an intent and Woxus writes a polished prompt straight into your editor.

Desktop Automation

Run terminal commands, create projects, and manage files — hands-free.

Local & Private

Memories, tasks, and settings live on your machine. No analytics, no telemetry.

Local Mini Agent

An on-device agent handles tasks in the background while you keep talking.

How it works

Woxus is an Electron app with a bundled backend. When you speak:

  1. Your microphone audio is streamed over a secure WebSocket to the Live API.
  2. The Live API handles speech recognition, reasoning, and voice synthesis in one connection.
  3. Woxus plays the reply through your speakers while keeping the mic open for interruption.
  4. If a computer task is needed, the Local Mini Agent runs it in the background so the conversation never stalls.

Getting Started

Follow these steps to install and begin using Woxus.

1. Install Woxus

Download the installer for your platform from the Woxus website:

  • macOS — DMG file. Drag Woxus to Applications.
  • Windows — NSIS installer (Woxus.exe).
  • Linux — AppImage.

2. Activate a License (or start your free trial)

On first launch you can either:

  • Start a free 10-minute trial (one per device).
  • Enter a license key you purchased from the Woxus website.

Licenses are bound to a single device. When the trial expires you'll be prompted to purchase or submit feedback.

3. Grant Permissions

Woxus needs two permissions for the full experience:

  • Microphone — for voice input (prompted automatically).
  • Accessibility (macOS) — required for the Prompt Writer to paste into your apps. You'll see an amber "Automation Permission Required" gate that opens System Settings for you. Enable Woxus there and return.

4. Talk to Woxus

Three ways to start a conversation:

  • Click the voice orb on the Home screen.
  • Use the floating desktop orb in the corner of your screen.
  • Press your global hotkey (default Cmd/Ctrl + Shift + P) to open the overlay.

Woxus greets you automatically, and if it has memory of you (for example, that you prefer Gujarati), it speaks to you in your language right away.

First things to try

"Hello Woxus!"

"Remember that I speak Gujarati."

"List the folders on my desktop."

"Write a prompt for an agent to read a PRD and make a plan."

Voice & Conversation

How voice works

Woxus uses a single WebSocket connection to the Live API. There are no separate speech-to-text or text-to-speech vendors — everything is handled in one connection, which keeps latency low.

Microphone ──16kHz PCM──▶ Live API WebSocket ──24kHz PCM──▶ Speakers
                                     │
                               Transcription text
                               (for memory + on-screen display)

Conversation features

  • Auto-greeting — Woxus greets you when you start a session; you don't have to speak first.
  • Barge-in / interruption — speak while Woxus is talking to stop it and take the floor.
  • Low latency — casual questions are answered directly, in under a second, without any tool detour.
  • Multilingual — Woxus understands and speaks many languages and matches your language automatically.
  • Memory-aware — durable facts you've saved (name, preferred language, preferences) are injected into the system prompt so Woxus knows them from the first turn.

The voice orb & overlay

Home orb — the large button on the Home screen. Click to start or stop the voice session.

Floating orb — a small always-on-top orb in the corner of your screen. Click it to open the main window, or use it to start talking from anywhere.

Overlay window — a minimal window opened by the global hotkey for quick interactions without leaving your current app.

Stopping a session

Click the orb again (or use the stop control) to end the session. This is an intentional stop — Woxus will not reconnect. Automatic reconnection only happens if the connection unexpectedly drops mid-conversation.

Prompt Writer

The Prompt Writer turns your spoken intent into a polished, detailed prompt and types it into the app where your cursor is — perfect for Claude Code, opencode, Cursor, ChatGPT, or any text input on your computer.

Prerequisite: Accessibility permission

Pasting into other apps requires macOS Accessibility permission. The first time you launch Woxus, an amber gate appears — click Open System Settings, enable Woxus under Privacy & Security → Accessibility, then return. The gate clears automatically.

How to use it

  1. Put your cursor in the input box of the app you want the prompt in.
  2. Start a voice session with Woxus and say something like:
    "Write a prompt for an agent to read a PRD and create a detailed plan."
  3. Woxus acknowledges ("On it…") and keeps listening while it composes the prompt in the background.
  4. When ready, the prompt is pasted at your cursor and you'll see a "✓ Prompt pasted" toast.

How it works under the hood

  • The main agent (Live API) generates the final prompt text.
  • The Local Mini Agent (on-device) executes a write_to_focused_input action.
  • Woxus copies the prompt to the clipboard and injects Cmd/Ctrl+V at the cursor via nut.js.
  • If the keystroke can't be injected (permission missing), the prompt stays on your clipboard and Woxus tells you to press Cmd/Ctrl + V manually.

Mini Agent & Computer Tasks

Woxus can operate your computer — run terminal commands, create projects, install packages, and manage files. Heavy tasks run in the background so you can keep talking to Woxus while it works.

What the Mini Agent can do

  • Run shell commands (list files, install packages, run builds, git operations).
  • Create projects and folders on your Desktop or anywhere.
  • Read and write files with validated extensions.
  • Write or paste a prompt into the focused app (see Prompt Writer).
  • Auto-heal failed commands up to 10 attempts with local, rule-based fixes.

Background execution

When you ask Woxus to do a task:

  1. Woxus says a short acknowledgment ("On it — I'll let you know when it's done.").
  2. The task runs in the background — you can keep talking to Woxus, ask other questions, or give new instructions.
  3. When the task finishes, Woxus reports the result.

This is why Woxus never goes silent for 20 seconds while a command runs.

The Tasks page

Every background command appears live on the Tasks page with its status (running / done / failed), exit code, and output — so you can watch progress in real time.

Memory System

Woxus remembers durable facts about you — your name, preferred language, preferences, projects, and goals — and uses them in every conversation.

Saving memories

  • Say "Remember that…" — Woxus saves the fact via a memory tool.
  • Example: "Remember that I speak Gujarati." → saved to memory.
  • You can also add/edit memories manually on the Memory page.

Using memories

  • At the start of every session, all active memories are injected into the system prompt.
  • Woxus knows facts before you say anything — for example, it greets you in Gujarati if that's your saved preference.
  • Memory works in text and voice, across sessions and app updates.

Privacy

Memories are stored in a local file on your machine. Nothing is uploaded to any server — the only network traffic is your live audio for the current conversation.

License & Free Trial

Free trial

  • First-time users get 10 minutes of full access.
  • One trial per device — a device identifier prevents reuse.
  • When the timer ends, you'll see a purchase / feedback screen.

License keys

  • Keys are verified against Woxus's license server on startup and periodically.
  • Each key is device-bound — one key per machine.
  • If a key is revoked, Woxus locks to enforce the license.
  • Offline cache keeps the app usable during brief connection loss; revocation is still enforced.

Purchasing

Visit the Woxus website (the admin/licensing portal) to purchase a key. Enter it on the License page and Woxus verifies and activates it instantly.

Troubleshooting

Woxus doesn't hear me / no response

  • Make sure the microphone permission is granted to Woxus.
  • Confirm the orb is showing the "Listening…" state and you're speaking after the greeting.
  • Check that your system mic isn't muted and Woxus isn't using the wrong input device.

The prompt is copied but not pasted

This means the macOS Accessibility permission isn't granted (or Woxus was updated since granting).

  • Reopen System Settings → Privacy & Security → Accessibility and ensure Woxus is toggled on.
  • If it's on, toggle it off and on again, then restart Woxus.
  • You can always paste manually with Cmd/Ctrl + V since the prompt is on your clipboard.

Woxus keeps reconnecting

Reconnecting on its own happens only when the session drops unexpectedly (network blip, API error). If you see it reconnect right after you stop, make sure you're clicking the orb to stop rather than force-quitting. Deliberate stops never reconnect.

"API key not configured"

Open Settings and add a valid API key (or select a model), then restart the voice session. The packed app passes your key to the backend automatically.

Voice is laggy / 20-second delays

Casual questions should get instant replies. Long delays usually mean a heavy computer task is running — that's expected and runs in the background; you can keep talking. If everything is slow, check your internet connection and API quota.

Where is my data stored?

Everything lives in a local data folder on your machine — memories, trial/license state, settings, and logs. Back it up to move to a new machine.

Frequently Asked Questions

General

Is Woxus free?

There's a free 10-minute trial per device. Full use requires a purchased license key.

Does Woxus work offline?

The interface, memory, and task tracking work offline. Live voice requires an internet connection.

Is my data private?

Yes. Memories, tasks, and settings stay on your machine. Only the live audio of the current conversation is transmitted for processing; no analytics or telemetry are collected.

Can I use it on multiple computers?

Yes, but each install needs its own license key, and memories/settings aren't automatically synced between devices.

Technical

Which AI model does Woxus use?

Woxus uses a state-of-the-art Live API for live voice, plus an on-device model for the Local Mini Agent.

How much disk space does it need?

Roughly 200MB for the app, plus ~2GB if you download the Local Mini Agent model for offline task automation.

Does Woxus collect telemetry?

No. No usage analytics or personal data are transmitted beyond the live conversation audio you initiate.

System requirements?

macOS 12+, Windows 10+, or a modern Linux distro. At least 4GB RAM and a dual-core CPU.
